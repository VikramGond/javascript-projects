# 🔐 Password Generator

A responsive and lightweight **Password Generator web application** built with **HTML, CSS, and JavaScript**.

This project is being built to strengthen my JavaScript fundamentals through practical development. It focuses on **randomization, arrays, strings, application state, DOM manipulation, form handling, validation, and browser APIs**.

## 📸 Preview

![Password Generator](assets/images/password-generator-preview.gif)

## 🚀 Features

- 🔢 Select password length using a range slider
- 🔠 Include uppercase letters
- 🔡 Include lowercase letters
- 🔢 Include numbers
- 🔣 Include special characters
- 📋 Copy generated passwords to the clipboard
- ⚠️ Validate password generation options
- 🚫 Prevent invalid password configurations
- 📱 Responsive layout
- 🎨 Clean and lightweight UI
- ⚡ Framework-free implementation

## 🛠️ Technologies Used

- **HTML5** — Application structure and form controls
- **CSS3** — Styling, layout, responsive design, and UI states
- **JavaScript (ES6+)** — Password generation, state management, validation, DOM manipulation, and event handling
- **Clipboard API** — Copy generated passwords to the clipboard
