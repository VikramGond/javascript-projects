# 📝 Todo App

A responsive and lightweight **Todo List web application** built with **HTML, CSS, and JavaScript**.

This project was built to strengthen my JavaScript fundamentals through practical development rather than relying on a framework. It focuses on **DOM manipulation, event handling, application state, array methods, localStorage, event delegation, dynamic rendering, and responsive UI development**.

## 📸 Preview

![Todo App](assets/images/todo-preview.gif)

## 🚀 Features

- ➕ Add new todos
- ⌨️ Add todos using the **Enter** key
- ☑️ Mark todos as completed
- 🖱️ Click the todo text to toggle completion
- ✏️ Edit existing todos
- ✅ Confirm edited todos
- ❌ Cancel editing
- 🗑️ Delete todos
- 🕐 Display the time when a todo was created
- 🔍 Filter todos by:
  - **All**
  - **Active**
  - **Completed**
- 💾 Persist todos using `localStorage`
- 🔄 Restore todos automatically after page refresh
- 🚫 Prevent empty todos from being added
- 📱 Responsive layout for different screen sizes
- 🎨 Custom dark-themed UI
- ☑️ Custom checkbox styling
- 🎯 Dynamic DOM rendering
- ⚡ Lightweight and framework-free

## 🛠️ Technologies Used

- **HTML5** — Application structure and semantic elements
- **CSS3** — Layout, responsive design, CSS Grid/Flexbox, custom checkbox, and UI styling
- **JavaScript (ES6+)** — Application logic, state management, DOM manipulation, event handling, filtering, and dynamic rendering
- **Web Storage API** — Persistent Todo data using `localStorage`
- **Font Awesome** — Edit, delete, confirm, and cancel icons
